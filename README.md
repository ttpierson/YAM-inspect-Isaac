# yam-sim-launchable

Bimanual [I2RT YAM](https://i2rt.com/products/yam-6-dof-arm) simulation for
[Isaac Lab](https://isaac-sim.github.io/IsaacLab/), packaged to become a Brev
launchable alongside [inspect-robots](https://github.com/robocurve/inspect-robots).

Status: the scene works (two arms, table, cube, plate, overview camera).
Launchable setup script and the inspect-robots embodiment come next.

## Layout

| Path | What |
|---|---|
| `assets/yam/` | YAM URDF + meshes vendored from [i2rt](https://github.com/i2rt-robotics/i2rt) (MIT, see `LICENSE.i2rt`, `SOURCE_COMMIT`) |
| `assets/yam/yam_sim.urdf` | Generated by `scripts/make_sim_urdf.py`: adds collision geometry upstream lacks |
| `yam_sim/assets.py` | `YAM_CFG`, one arm as an Isaac Lab `ArticulationCfg` |
| `yam_sim/scene.py` | `BimanualYamSceneCfg`, the tabletop scene |
| `scripts/view_scene.py` | Spawns the scene and runs a demo motion |

## Run

Inside an Isaac Lab 2.3 environment:

```bash
python scripts/view_scene.py                                   # GUI
python scripts/view_scene.py --headless --screenshots out/ --steps 600
```

Each arm exposes `joint1`-`joint6` plus the two finger joints `joint7`/`joint8`
(0 = closed, -0.04695 m = open). At zero joint angles the gripper points along +X.
